# 🛍️ Shopping Mart

A simple and user-friendly online Shopping Mart website where users can browse products, filter products by category, add items to the cart, manage quantities, and place orders.

## 📌 Project Overview

Shopping Mart is a frontend mini project created using HTML, CSS, and JavaScript.

The main goal of this project is to provide a simple shopping experience where users can easily explore products, manage their cart, and complete an order.

## ✨ Features

- Browse products
- Filter products by category
- Add products to cart
- Increase and decrease quantity
- Remove items from cart
- Calculate subtotal
- Calculate 6% tax
- Calculate total price
- Place an order
- Customer order form
- Payment method selection
- Order confirmation
- Automatic order number generation
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How It Works

1. Products are displayed dynamically using JavaScript.
2. Users can filter products by category.
3. Products can be added to the cart.
4. Users can increase, decrease, or remove cart items.
5. Subtotal, tax, and total are calculated automatically.
6. The Place Order button opens the order form.
7. The user enters the required details.
8. After confirmation, an order number and success message are displayed.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a browser.

No backend or database is required.
